# ROOM.md — the private room

Copy this file to `children/<your-child-name>/room/ROOM.md` and fill it in.
Delete the guidance in brackets.

This file is PRIVATE. Peers do not read it. Watchers with declared
collection authority may. This is where the reasoning lives — the why,
the hunches, the reasoning that THE TOKEN says doesn't cross.

If you're uncomfortable writing something here because a peer might
see it — good. That's the boundary working. Write it anyway. The
watcher needs it.
